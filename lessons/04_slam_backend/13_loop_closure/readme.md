# 13. 루프 폐쇄 후보 검색

카메라가 같은 장소를 다시 보았을 때, 과거에 본 장면 중 어느 사진이 가장 비슷할까? 이 실습은 ORB 특징을 DBoW3 시각 단어로 변환하고, 질의 사진보다 먼저 촬영된 사진에서 유사도가 높은 후보를 최대 3장 찾는다. 파일 번호를 촬영 순서로 사용한다.

저장소 루트에서 실행한다.

```bash
./lessons/04_slam_backend/13_loop_closure/run.sh
```

첫 화면의 왼쪽은 마지막 사진인 `10.png`, 오른쪽은 1위 후보다. 아래의 작은 사진에서 순위, 파일명, 점수를 함께 읽을 수 있다. 후보를 바꾸면서 두 사진에 공통으로 보이는 물체와 배치를 비교해 본다.

| 조작 | 기능 |
|---|---|
| `n` / `p` | 다음 / 이전 질의 사진 |
| 작은 사진 클릭 또는 `1`, `2`, `3` | 해당 순위 후보를 오른쪽에 크게 표시 |
| `m` | 두 사진에서 유사한 ORB 특징점을 선으로 연결하거나 숨기기 |
| `q` 또는 `Esc` | 종료 |

**점수**는 제공된 사전에서 두 사진의 시각 단어 분포가 얼마나 비슷한지 나타낸다. **연결선**은 ORB 기술자에 해밍 거리 비율 검사(0.75)를 적용한 뒤 거리가 짧은 순으로 최대 20쌍을 표시한다. 화면의 순위는 재방문 후보를 고르는 단계이며, 루프 폐쇄를 확정하려면 기하 검증이 추가로 필요하다. 첫 사진에는 검색할 과거 사진이 없어 후보가 비어 있다.

실행 스크립트는 사전 학습 예제도 수행한다. 검색에는 제공된 `data/vocab_larger.yml.gz`를 사용한다. 학습을 건너뛰고 창만 다시 열려면 이 실습의 `build/`에서 다음 명령을 실행한다.

```bash
./loop_closure ../data/vocab_larger.yml.gz ../data/
```

같은 명령 앞에 `SLAM_HEADLESS=1`을 붙이면 현재 폴더에 첫 화면 `loop_closure.png`와 대응선을 켠 `loop_closure_matches.png`를 저장한다. 터미널에서는 모든 이미지 쌍의 점수와 전체 데이터베이스 순위(0부터 시작하는 ID), 과거 후보 순위(파일명)를 함께 확인할 수 있다.
