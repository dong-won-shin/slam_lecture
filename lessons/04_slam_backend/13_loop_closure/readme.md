# 13. 루프 폐쇄 후보 검색

카메라가 같은 장소를 다시 보았을 때, 과거에 본 장면 중 어느 사진이 가장 비슷할까? 이 실습은 ORB 특징을 DBoW3 시각 단어로 변환하고, 질의 사진보다 먼저 촬영된 사진에서 유사도가 높은 후보를 최대 3장 찾는다. KITTI Odometry 시퀀스 00의 왼쪽 컬러 카메라(`image_2`)에서 시간 순서대로 뽑은 도로 사진 10장을 사용한다.

저장소 루트에서 실행한다.

```bash
./lessons/04_slam_backend/13_loop_closure/run.sh
```

첫 화면에서 왼쪽의 `10.png`는 주택가를 다시 지날 때의 사진이고, 오른쪽 1위 후보 `1.png`는 처음 지날 때의 사진이다. 왼쪽 차로에 나타난 흰 차, 두 사진에서 일치하는 가로수와 건물 모서리를 비교해 본다. 아래의 2위와 3위 후보를 누르면 다른 교차로와 비교할 수 있다.

2번 질의부터 보려면 실행 명령 끝에 `2`를 붙인다. 이때 과거 사진은 `1.png` 한 장뿐이어서 검색 1위가 된다. KITTI 기준 궤적에서 두 사진의 촬영 위치는 229.3m 떨어져 있다. 특징점 대응이 6개뿐이라 오른쪽에는 `No verified loop`가 표시된다. 아래의 `Rejected` 카드를 누르면 두 사진을 직접 비교할 수 있다.

| 조작 | 기능 |
|---|---|
| `n` / `p` | 다음 / 이전 질의 사진 |
| 작은 사진 클릭 또는 `1`, `2`, `3` | 해당 순위 후보를 오른쪽에 크게 표시 |
| `m` | 기하 검증의 인라이어 대응점 최대 20쌍을 선으로 연결하거나 숨기기 |
| `q` 또는 `Esc` | 종료 |

**검색 점수**는 두 사진의 시각 단어 분포가 얼마나 비슷한지 나타낸다. 상위 후보마다 ORB 기술자에 해밍 거리 비율 검사(0.75)를 적용하고 양방향 최근접 대응만 남긴다. 대응이 15개 이상이면 RANSAC으로 기본 행렬을 추정한다. 에피폴라 선까지의 허용 거리는 1.5픽셀이며, 인라이어가 15개 이상이고 전체 대응의 절반 이상이면 `Verified`로 표시한다. 예를 들어 `10.png`와 `1.png`는 대응 163개 중 151개가 인라이어다. 기본 화면은 검증을 통과한 후보 중 검색 순위가 가장 높은 사진을 보여준다. 첫 사진에는 검색할 과거 사진이 없어 `No earlier candidate`가 표시된다.

실행 스크립트는 사전 학습 예제도 수행한다. 검색에는 제공된 `data/vocab_larger.yml.gz`를 사용한다. 학습을 건너뛰고 창만 다시 열려면 이 실습의 `build/`에서 다음 명령을 실행한다.

```bash
./loop_closure ../data/vocab_larger.yml.gz ../data/
```

같은 명령 앞에 `SLAM_HEADLESS=1`을 붙이면 현재 폴더에 첫 화면 `loop_closure.png`와 대응선을 켠 `loop_closure_matches.png`를 저장한다. 터미널에서는 모든 이미지 쌍의 점수와 전체 데이터베이스 순위(0부터 시작하는 ID), 과거 후보 순위(파일명)를 함께 확인할 수 있다.

## 주행 구간과 출처

저장소의 `1.png`부터 `10.png`까지에 대응하는 원본 프레임 ID는 순서대로 다음과 같다.

```text
000015  000505  001100  001850  002100  002600  003670  003950  004230  004464
```

공식 기준 궤적(`poses/00.txt`)에서 프레임 15부터 4464까지 인접 위치 사이의 3D 거리를 더하면 약 3.63km다. 두 끝점의 직선거리는 약 0.4m다. 이 위치 정보는 재방문 사진을 고르는 데 사용했으며, 뷰어의 순위는 사진의 DBoW3 점수로 계산한다.
