# 14. 포즈 그래프 최적화

구면을 따라 이동한 센서의 초기 위치가 얼마나 어긋나 있는지, g2o가 상대 자세 제약을 적용하면 궤적이 어떻게 변하는지 한 3D 창에서 비교한다. 예제 데이터 `sphere.g2o`에는 SE(3) 자세 2,500개와 상대 자세 제약 9,799개가 있다.

저장소 루트에서 실행한다.

```bash
./lessons/04_slam_backend/14_pose_graph/run.sh
```

왼쪽은 입력 그래프이고 오른쪽은 기본적으로 최종 그래프다. 두 그림은 같은 시점과 축척을 쓰며 Y축이 위를 향한다. **`0`을 누른 뒤 `n`을 누르면** 오른쪽 그래프에서 실제 최적화 반복을 하나씩 볼 수 있다. 각 패널 아래의 `chi-squared`는 상대 자세 오차에 각 제약의 정보 행렬을 적용한 가중 제곱합이다.

점은 각 자세의 3D 위치이고 선은 입력 파일에 기록된 제약이다. 청록색 선은 ID가 연속된 자세를, 회청색 선은 그 밖의 자세를 연결한다. 노란 고리는 기준 좌표계를 고정하는 자세이며 이 데이터에서는 ID 0이다.

| 조작 | 기능 |
|---|---|
| 어느 쪽에서든 드래그, `+` / `-` | 두 그래프를 함께 회전, 확대 / 축소 |
| `n` / `p` | 오른쪽 그래프의 다음 / 이전 반복 |
| `0` / `e` | 초기 / 최종 상태로 이동 |
| `c` | 연속된 자세 사이의 경로를 보기 위해 나머지 제약을 숨기거나 다시 표시 |
| `r` / `q` 또는 `Esc` | 시점 초기화 / 종료 |

실행하면 최적화한 자세와 제약을 실습의 `build/result.g2o`에 저장한다. 창 없이 실행하면 같은 폴더에 초기·최종 비교 화면 `pose_graph.png`도 저장한다.

```bash
SLAM_HEADLESS=1 ./lessons/04_slam_backend/14_pose_graph/run.sh
```
