# 06. 에피폴라 기하

왼쪽 사진에서 고른 점과 같은 장면의 점은 오른쪽 사진의 어디에 나타날까? 두 카메라의 중심과 장면의 점이 만드는 평면을 **에피폴라 평면**이라고 한다. 이 평면이 오른쪽 카메라의 영상면과 만나는 직선이 **에피폴라 선**이다. 이 실습에서는 같은 장면을 두 위치에서 촬영한 사진 위에 그 선을 그린다.

## 실행

저장소 루트에서 다음 명령을 실행한다.

```bash
./lessons/02_visual_odometry/06_epipolar_geometry/run.sh
```

1. 왼쪽 사진에서 모니터 모서리나 음료수 캔에 표시된 작은 점을 클릭한다. 가장 가까운 대응점에 노란 고리가 표시된다.
2. 오른쪽 사진에서 노란 선과 청록색 고리를 비교한다. 선은 왼쪽 점과 기본 행렬로 예측한 위치들의 집합이고, 고리는 ORB로 찾은 실제 대응점이다. 아래 숫자는 고리 중심에서 선까지의 수직 거리로, 원본 사진의 픽셀 단위다.
3. `n` 또는 스페이스로 다음 대응점, `p`로 이전 대응점을 본다. `q` 또는 `Esc`로 창을 닫는다.

창 없이 첫 대응점의 시각화를 저장할 수도 있다.

```bash
SLAM_HEADLESS=1 ./lessons/02_visual_odometry/06_epipolar_geometry/run.sh
```

결과는 이 실습의 `build/epipolar_geometry.png`에 저장된다. 다른 사진 두 장은 `build/pose_estimation_2d2d`의 첫 번째·두 번째 인자로 전달한다.

## 계산

ORB 대응점으로 기본 행렬 $F$를 RANSAC으로 추정하고, 추정에 동의하는 대응점만 화면에 표시한다. 왼쪽 픽셀을 동차좌표 $x_1=(u_1,v_1,1)^T$로 쓰면 오른쪽 에피폴라 선은 $l_2=F x_1=(a,b,c)^T$이다. 이상적인 오른쪽 대응점은 $a u_2+b v_2+c=0$을 만족한다. 실제로는 특징점 검출과 행렬 추정에 오차가 있어 작은 거리가 남을 수 있다.

터미널에는 기본 행렬 $F$, 본질 행렬 $E$, 상대 회전 $R$과 이동 방향 $t$가 출력된다. $E$와 상대 자세 계산에는 샘플 카메라의 내부 파라미터를 사용한다. 다른 카메라로 촬영한 사진의 자세까지 해석하려면 소스의 `K`를 해당 카메라의 보정값으로 바꾼다.
