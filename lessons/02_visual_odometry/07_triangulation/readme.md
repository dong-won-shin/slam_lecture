# 07. 두 시점 삼각측량

한 사진에서 고른 픽셀은 카메라 중심에서 나가는 광선 하나를 정한다. 두 번째 사진에서 같은 장면의 점을 찾으면 두 번째 광선도 얻는다. 이 실습에서는 두 광선과 삼각측량으로 복원한 점을 3D로 돌려 보며 두 사진의 대응점과 비교한다.

## 실행

저장소 루트에서 다음 명령을 실행한다.

```bash
./lessons/02_visual_odometry/07_triangulation/run.sh
```

왼쪽은 첫 번째 카메라 좌표계에서 본 3D 장면이다. 노란색과 청록색 피라미드는 두 카메라의 위치와 방향을, 두 선은 오른쪽 사진에서 고리로 표시한 픽셀의 관측 광선을 보여준다. 흰 고리는 선택한 복원점이다. 관측 오차가 있으면 두 광선은 복원점 근처에서 약간 어긋날 수 있다.

| 조작 | 확인할 수 있는 것 |
|---|---|
| 왼쪽 3D 영역에서 드래그 | 시점을 바꿔 두 카메라 사이의 간격과 광선이 이루는 각도 보기 |
| `n` 또는 스페이스 / `p` | 다음 / 이전 복원점과 두 사진의 대응점 보기 |
| `+` / `-` | 확대 / 축소 |
| `r` / `q` 또는 `Esc` | 시점 초기화 / 종료 |

깊이 `Z1`은 첫 번째 카메라의 광축 방향 좌표다. 두 사진만으로 복원한 장면에서는 두 카메라 중심 사이의 거리(베이스라인)를 1로 둔다. 예를 들어 `Z1 = 12.89`이면 그 점의 깊이는 베이스라인의 12.89배다. 카메라 좌표계에서 X는 영상 오른쪽, Y는 영상 아래쪽, Z는 광축 전방이다. 왼쪽 3D 뷰에서도 +Y축은 화면 아래쪽을 향한다.

## 계산과 이미지 저장

ORB 대응점으로 본질 행렬을 추정하고 RANSAC과 양의 깊이 검사를 통과한 점을 표시한다. 첫 번째 카메라의 투영 행렬은 $K[I|0]$, 두 번째는 $K[R|t]$이다. 따라서 첫 번째 카메라 좌표계에서 두 번째 카메라의 중심은 $-R^T t$이다. 관측 광선은 각 사진의 픽셀에 $K^{-1}$을 적용해 구한다. 다른 카메라로 촬영한 사진을 사용하려면 소스의 내부 파라미터 $K$를 보정값에 맞춘다.

아래 명령은 창 없이 기본 시점의 `triangulation_overview.png`와 깊이 색상을 입힌 `view1.png`, `view2.png`를 실습 폴더의 `build/`에 저장한다.

```bash
SLAM_HEADLESS=1 ./lessons/02_visual_odometry/07_triangulation/run.sh
```
